# 跨專案資安優先原則

整理日期：2026-11-16（Asia/Taipei）

適用於程式功能新增、修改及審查。公司政策與已核准的專案規範優先適用。

開發前先辨識變更入口、資料、操作者與外部依賴，再依下表讀取所有適用主題。沿用專案既有控制。資料分類或授權規則未確認時，維持現有安全限制並記下影響。記錄適用項目、實作位置、驗證結果和待確認事項，區分本機模擬與正式環境驗證。

| 本次變更涉及 | 開發前讀取 |
|---|---|
| 登入、Session、API 權限、查詢、下載、匯出、快取 | [身分授權與資料存取](身分授權與資料存取.md) |
| 表單、SQL、前端輸出、Cookie、跨來源、檔案、外部連線 | [輸入輸出與外部連線](輸入輸出與外部連線.md) |
| 個資、秘密、日誌、重要寫入、重送、並行、復原 | [敏感資料與稽核復原](敏感資料與稽核復原.md) |
| 套件、建置、發布、開發入口隔離 | [套件建置與部署](套件建置與部署.md) |
| AI、工具權限、外部資料、人工覆核、雲端責任 | [AI與雲端整合](AI與雲端整合.md) |

例如新增訂單匯出，先讀身分授權與資料存取。涉及個資或重要操作稽核時，再讀敏感資料與稽核復原。

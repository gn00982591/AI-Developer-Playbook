# 輸入輸出與外部連線

[返回開發資安索引](README.md)

| 變更入口 | 實作細項 | 最少驗證情境 |
|---|---|---|
| 表單、API 契約、SQL | 後端檢查型別、必填、長度、數值範圍、列舉及業務關聯。寫入時明列可修改欄位。SQL 使用參數，排序欄位等識別字以明確清單映射。 | 缺欄位、超長、非法列舉、非允許欄位、有效的邊界值。 |
| 前端呈現、語系內容、HTML | 使用框架預設的文字跳脫。必要的富文字透過既有清理機制。網址屬性依用途驗證協定。 | 文字中的標記按文字顯示，受限的富文字及網址依規則處理。 |
| Cookie、跨來源請求 | 依架構核對 HTTPS 與加密傳輸邊界。Cookie 依用途設定 Secure、HttpOnly、SameSite。以 Cookie 識別使用者的寫入操作，按架構套用防偽機制。跨來源存取只開放已核准來源與必要方法。 | 合法來源可用，未核准來源及缺少必要防偽資訊的寫入請求被拒絕。 |
| 檔案上傳、下載與保存 | 限制大小、類型與數量。按用途核對檔案內容，使用系統產生的儲存名稱並避免由原始檔名決定儲存路徑。下載由後端重查權限。 | 超限、類型不符、同名檔、無權限下載及部分失敗後的清理。 |
| 外部連結、第三方 API、雲端 | 核對目的地、協定、資料流向及責任分工。伺服器主動連線時按用途限制目的地。設定逾時，僅在可安全重試時重試。 | 未核准目的地、逾時、重送及第三方錯誤。確認回應及日誌不洩漏秘密。 |

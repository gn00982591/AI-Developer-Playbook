## 遷移與退役

- 在隔離環境驗證空庫初始化及所有支援的升級來源版本，帶代表性既有資料。記錄相依順序、可重跑語意、中途失敗的回滾或復原途徑，以及最低必要執行權限。
- 資料轉換以來源與業務識別建立可追查的映射，處理不同舊表流水號重複。核對穩定識別、主從關聯、有效授權、稽核及轉換前後業務結果。
- 退役前盤點資料庫物件、專用授權、應用呼叫、服務、排程、前端入口、歷史網址及發布流程。有使用者或其他依賴時記錄所需相容行為。確認可退役後，在同一變更處理專用程式、授權、部署／升級腳本、測試、文件及規格引用。
- 驗空庫、含資料升級、重跑、受控中途失敗、必要權限及新舊入口。比對主鍵映射、關聯及業務結果，驗證退役後仍使用的依賴。對照部署或發布後的實際產物與版本庫。
- 正式異動依既有授權執行。隔離測試、目標庫部署、發布產物核對及正式驗收各自記錄環境、身分與結果。

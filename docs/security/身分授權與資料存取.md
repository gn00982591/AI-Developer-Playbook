# 身分授權與資料存取

[返回開發資安索引](README.md)

| 變更入口 | 實作細項 | 最少驗證情境 |
|---|---|---|
| 登入、SSO、Session | 使用既有身分服務。由後端驗證權杖的簽章、簽發者、對象及效期，並確認登出、逾時與秘密管理方式。登入錯誤避免揭露帳號是否存在。 | 未登入、已過期、登出後再請求、切換帳號後無前次資料。 |
| API、功能權限、管理異動 | 每個受保護操作在後端檢查身分、操作與目標資料權限。依目前有效授權判斷，缺少權限預設拒絕。前端選單及按鈕狀態只作介面呈現。 | 一般使用者、管理角色、權限撤銷後的下一次請求，以及不同公司或模組的資料隔離。 |
| 查詢、下載、匯出、快取 | 在資料來源或 API 套用授權範圍。查詢、總筆數及匯出使用一致的資料與欄位限制。快取不得跨身分沿用，登出或撤權後清除失效資料。 | 空授權、部分授權、跨公司及切換帳號。比對畫面、API 與匯出結果。 |

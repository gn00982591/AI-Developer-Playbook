# Explore Rules

適用於需求、問題原因或修改位置尚未清楚的任務。

## 目標

以最小探索範圍找出必要的現況流程、根因、影響檔案與修改方向。

## 規則

- 先搜尋，再讀檔案。
- 不全面掃描 Repository。
- 只讀與需求直接相關的程式。
- 不修改程式。
- 不做無關架構分析。
- 找到必要呼叫鏈即可。
- 找不到時再逐步擴大搜尋範圍。

## 建議輸出

1. Current Flow
2. Root Cause
3. Affected Files
4. Affected API / SP / Table
5. Proposed Direction
6. Unknowns

# 前端共用元件與語系

涉及前端設計、實作、驗證或審查，或集中語系的資料來源與接線時，按需套用。受保護畫面另依開發資安索引載入工作階段與資料存取規則。

## 實作

- 頁面與 API 呼叫依模組及功能群組放置，與端點、資料存取及測試的責任相對應。跨模組的傳輸、身分及語系能力沿用共用層。搬移時核對匯入、路由、註冊、呼叫契約、測試及文件。
- 設計前查既有共用元件、展示頁與同類畫面。沿用已有能力，缺少時最小幅度補齊並回歸其他使用處。從實際頁面確認共用引用及配置生效。
- 文字、錯誤與無障礙名稱沿用集中語系及穩定 Key。依專案規格驗證切語、缺譯回退、插值、長文字、按需載入、快取、重試與輸入保留。

## 集中語系現況與資料來源切換

接續既有集中語系功能前，沿畫面、API 和資料存取入口核實以下四項。更新規格、Agent 指引或交付紀錄時，逐項填寫環境、結果、證據與缺口。

| 核實項目 | 證據 |
| --- | --- |
| 畫面與 API 實作 | 從實際頁面、路由及處理程式確認維護、按需載入與快取哪些已實作。 |
| 應用程式目前讀寫來源 | 核對生效設定、依賴註冊與讀寫路徑，確認目前使用的來源及目標切換是否已接線。 |
| 結構及種子部署 | 以實庫結構、種子查詢或部署紀錄確認各環境的實際狀態。 |
| 目標環境端到端驗收 | 以實際頁面和 API 驗證目標來源，記錄執行身分、結果與覆蓋範圍。 |

資料來源切換依專案既有變更流程處理。以實際 API 合法保存，重啟應用後查回，核對資料版本及快取更新。模擬部分失敗，確認受影響的舊內容依契約保留，重試可恢復。採按需載入時，驗證首次進入、返回已載入功能、手動重載、失敗與重試，以及遲到回應和跨身分隔離。SQL 結構及種子部署的證據與應用程式接線的證據各自記錄。

## 驗收

尺寸與語系矩陣依專案規格。對適用入口記錄已驗尺寸、語系、互動與無障礙，以及待人工審閱或實機驗證的項目。

| 檢查對象 | 虛構案例與預期 |
| --- | --- |
| 維護彈窗 | 開啟「北區據點」後焦點進入表單，鍵盤可完成操作並在關閉時回到原入口。非法輸入有提示，取消、保存、草稿、撤權各依契約處理，窄畫面仍能操作。 |
| 查詢結果頁 | 據點搜尋顯示載入、正常、空結果與錯誤。重試可恢復，分頁和匯出符合查詢條件及授權。 |
| 集中翻譯 | 以 `site.edit.title` 驗證可見標題與無障礙名稱，在實際彈窗切語。驗證缺譯回退、參數插值與長字串，重試載入後保留輸入。 |

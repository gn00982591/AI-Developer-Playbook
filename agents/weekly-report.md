# 週報規則（Weekly Report）

適用於產出、整理及更新週報。

1. 確認報告期間與資料截止日，讀取本期來源與既有週報。先查專案入口或文件是否指定週報範本。若有指定，專案規則須提供可直接開啟的引用，撰寫前讀取並核對章節順序、必填欄位、版面及交付格式。指定範本優先。未指定時沿用既有週報格式。
2. 無指定範本且無既有週報時，依本期完成事項、進行中事項、待解問題與下一步整理。依來源呈現本期變化及仍待追蹤的事項，保留已確認的狀態、負責人與日期，未知資訊標記待確認。
3. 若本次也更新專案進度，依 [Project Progress Rules](project-progress.md) 同步 MD 與 Excel，並核對週報所述狀態及日期。單獨產出週報時，依已確認來源彙整。
4. 交付前核對報告期間、事實、格式及必要欄位。指定範本或必要來源無法讀取時，列出未核對項目，可先交付已確認內容的草稿，待驗證後再標記正式週報完成。

## 英文支援週報標準

使用者要求簡短英文支援週報或指定只提供 `Support content` 時，依本節交付可直接貼入儲存格的文字。使用者明確要求完整週報或更新工作簿時，依上述範本規則處理。

- 報告期間依使用者指定。若指定「last Friday through today」，依使用者時區取上週五至今天，含首尾兩日。
- 專案週報只採用可由目前專案的對話或檔案確認的資料。案件須屬於該專案，且本期有支援處理或追蹤更新。不得以其他專案、一般對話或跨專案記憶補列案件。
- 每案一段，合併同一工單的更新。每段以處理日期 `M/D:` 開頭，例如 `11/25:`。用一至兩句簡短英文記錄工單編號（如有）、處理結果和待解問題（如有）。
- 只輸出 `Support content` 的純文字。省略標題、表格、項目符號及狀態等其他欄位。交付前核對案件歸屬、報告期間及日期格式。

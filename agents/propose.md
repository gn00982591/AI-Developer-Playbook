# Propose Rules

適用於需求已確認，需要建立正式變更規格的任務。

## 規則

- 優先使用 Explore Findings。
- 不重新掃描 Repository。
- 只有 Findings 明確不足時才補充必要搜尋。
- 規格保持精簡，避免重複描述已知背景。

## 建議輸出

- Scope
- Out of Scope
- Current Behavior
- Expected Behavior
- Technical Design
- Affected Files
- DB Impact
- Acceptance Criteria
- Tasks

涉及資料存取時，另套用 [Data Access Rules](data-access.md)，沿用同版本已核對的索引與來源，只補讀本次直接相依內容。

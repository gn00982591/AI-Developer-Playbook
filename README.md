# AI Developer Playbook

個人的 AI 開發工作方法與實務筆記。

本 Repository 用來保存可長期沿用的開發流程、Prompt、Token 節省原則與工作 SOP，不保存任何公司專有程式碼、帳號、連線資訊或機密資料。

## 使用原則

- 討論內容不等於正式版本。
- 只有在明確確認「更新 Playbook」或「這版確認，可以更新」後，才更新 Repository。
- 每次正式更新都透過 Git commit 保留版本紀錄。
- 優先保存可跨公司、跨專案重複使用的方法、模板與檢查表。

- `docs/OPSX_Workflow.md`：OPSX 開發流程與各階段責任。
- `docs/Token_Saving.md`：降低 AI / Codex Token 使用量的原則。
- `CHANGELOG.md`：正式版本更新紀錄。
